## Jupyter Template

### dependencies

- [`uv`](https://docs.astral.sh/uv/) - An extremely fast Python package and project manager, written in Rust.
- [`just`](https://github.com/casey/just) - Just a command runner

### commands
- `just convert` - Convert notebook file to html
- `just format` - Format notebook file
- `just lint` - Lint notebook file
- `just lint-fix` - Lint and fix notebook file
